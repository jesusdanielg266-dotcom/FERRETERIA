# FerroHub – Ferretería en línea

Prototipo y tienda funcional de una ferretería en línea (estilo tienda de moda, pero de ferretería).

## Funcionalidades
- **Login** y creación de cuenta, además de modo invitado
- **Cliente:** catálogo, buscador, detalle de producto, **carrito**, **lista de deseos**, **historial de compra** con detalle de pedido, ajustes de cuenta y ayuda con línea directa a un asesor
- **Administrador:** panel con resumen, inventario de productos, pedidos, base de datos de clientes, mensajes y ajustes
